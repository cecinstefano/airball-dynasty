# Wallpapers do popup do Draft

Substitua os arquivos abaixo mantendo exatamente os mesmos nomes:

pick-01.jpg
pick-02.jpg
pick-03.jpg
...
pick-16.jpg

Cada arquivo corresponde ao wallpaper do popup daquela pick sorteada.

Recomendado:
- Formato: JPG
- Proporção: 16:9
- Tamanho ideal: 1920x1080
- Evite textos muito importantes nas bordas, pois o popup tem overlay escuro/roxo por cima para manter a leitura.

Exemplo:
Quando sair a Pick #1, o site usa:
assets/draft-wallpapers/pick-01.jpg

Quando sair a Pick #16, o site usa:
assets/draft-wallpapers/pick-16.jpg
